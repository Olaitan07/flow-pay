# Epic 21 — Audit Trail

## Objective

Provide traceability for sensitive customer, administrative, and financial activities.  
Audit Information  
Where appropriate:  
WHO  
WHAT  
WHEN  
RESOURCE  
RESULT  
CORRELATION ID  
Auditable Events  
Examples:  
Authentication.  
Transfer initiation.  
Wallet freeze.  
Wallet unfreeze.  
Limit modification.  
KYC status changes.  
Reversal initiation.  
Administrative actions.  

## Functional Requirements

Audit records must be protected from unauthorized alteration.  
Sensitive secrets must not be written to audit logs.
