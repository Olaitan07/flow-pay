# Epic 13 — Beneficiaries

## Objective

Allow customers to save trusted payment destinations.  

## User Story

As a customer,  
I want to save beneficiaries,  
so that I can make future transfers conveniently.  

## Functional Requirements

Customers should be able to:  
Add beneficiary.  
View beneficiaries.  
Remove beneficiary.  
Transfer to beneficiary.  
Sensitive beneficiary changes may require additional authentication.  

## Acceptance Criteria

A customer must not access another customer's private beneficiary list.  
Invalid beneficiary information must not be saved as a valid beneficiary.
